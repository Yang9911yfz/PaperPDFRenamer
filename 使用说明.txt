论文 PDF 快速重命名 v1.0（Windows + macOS）

这两个版本包含相同的窗口程序，不依赖 Zotero、不需要 API key、不收费。
它是 Python 源码工具包，不是免安装 EXE/APP。首次需要 Python 和联网安装依赖。

一、Windows（建议 Windows 10/11）
1. 将 ZIP 完整解压到一个固定文件夹，不要直接在压缩包里运行。
2. 从 https://www.python.org/downloads/windows/ 安装 Python 3.10 或更新版本。
   建议 3.12 或 3.13，安装时勾选 Add python.exe to PATH，保留 Tcl/Tk。
3. 双击 Windows_Setup.bat，等待安装完成。此步骤只需做一次。
4. 双击 Windows_Start.bat 打开工具。也可将 PDF/文件夹拖到 Windows_Start.bat 上预先添加。

二、Mac（Intel / Apple Silicon 均使用 Python 本机版本）
1. 将 ZIP 完整解压到固定文件夹。
2. 从 https://www.python.org/downloads/macos/ 安装官方 Python 3.10 或更新版本。
   建议 3.12 或 3.13。官方安装包含窗口界面所需 Tcl/Tk；系统自带 Python 可能不包含。
3. 双击 Mac_Setup.command，等待安装完成。此步骤只需做一次。
4. 以后双击 Mac_Start.command，通过窗口的“添加 PDF / 添加文件夹”选择文件。
5. 如果提示没有执行权限：打开终端，输入 chmod +x 和一个空格，将两个 .command 文件
   从 Finder 拖进终端，再按回车。也可以在终端输入 bash 和一个空格，拖入要运行的
   .command 文件，再回车。
6. 如出现 Python HTTPS 证书错误，运行“应用程序 / Python 版本号 / Install Certificates.command”。
7. 如遇 macOS 安全策略阻止执行，请先核对源码；受单位管理的电脑需遵循管理员策略。

三、日常操作（两端相同）
1. 将一个或多个 PDF、文件夹直接拖入窗口即可添加，也可使用添加按钮。
   支持中文和带空格的路径，重复文件和非 PDF 自动跳过；文件夹只处理第一层，不递归。
   拖入后仍需点击“识别 / 刷新预览”。处理过程中暂不接受拖入。
2. 选命名格式：仅标题 / 年份 - 标题 / 作者 - 年份 - 标题。
3. 点击“识别 / 刷新预览”，等待结果。每次联网请求有 18 秒超时。
4. 核对原文件名和新名称。双击一行可以修改新名称，留空即跳过该文件。
5. 点击“执行重命名”，确认后在原文件夹修改文件名。
6. 同名自动加 (2)、(3) 等编号，不覆盖已有文件。
7. 撤销：点“撤销一次操作”，选择本次操作日志。
   日志保存在用户主目录的 PaperPDFRenamer_Logs 文件夹。
   原文件名已占用、PDF 内容已变化或文件被移动时，撤销会跳过该条。
   撤销后重新添加文件，刷新列表。

四、识别方式与边界
- 从 PDF 首页和元数据提取 DOI，向 Crossref 查询题录，仅发送 DOI，不上传 PDF。
- 无 DOI 时尝试 PDF 自带标题，缺失年份/作者时省略这些字段。
- 首页存在多个不同 DOI 时跳过，避免选中参考文献。即使只找到一个 DOI，也请核对标题。
- 扫描版不做 OCR；无 DOI 的 arXiv 论文只尝试内嵌标题，可能需要手动填写。
- DOI 换行、特殊字符、Crossref 无题录、网络不可用时可能识别失败，保留原名。
- 标题过长会截短；数学标记可能不能完全还原；不同出版社识别效果有差异。
- 只修改路径名称，不改 PDF 内容或元数据，不导入 Zotero。
- 请先关闭正在打开的 PDF，Windows 阅读器可能锁定文件。
- 适合普通本地磁盘（Windows NTFS、Mac APFS 等）。不支持硬链接的磁盘/网盘会报错并保留原文件。
- 工具在处理期间请勿同时移动、编辑文件或从其他程序重命名它们。
- 已在 Windows 上使用并检查拖放、名称编辑和界面布局；尚未在真实 macOS 桌面验证。

五、排错
- 提示 Python 找不到：安装官方 Python 后重新打开启动文件。
- 安装失败：检查网络能否访问 pypi.org，保存安装窗口报错。
- _tkinter 缺失：改用 python.org 官方安装程序，保留 Tcl/Tk；重新运行 Setup。
- 如果移动了整个工具文件夹，删除里面的 .venv 文件夹，再运行对应 Setup 重建环境。
- 修改命名格式后，需要重新点击“识别 / 刷新预览”。
- 后台识别时窗口可响应，但不允许开始其他操作。先等处理结束再关闭窗口。

源码：paper_renamer.py（核心及界面）、setup.py（安装）
依赖：pypdf 6.10.0、tkinterdnd2 0.6.4，首次安装从 PyPI 获取。Python 自带 tkinter、urllib 等。
Crossref API 文档：https://www.crossref.org/documentation/retrieve-metadata/rest-api/

六、窗口拖放
- 已有版本升级后，重新运行对应 Setup 安装 tkinterdnd2 0.6.4，再重启窗口。
- 若拖放组件缺失或加载失败，窗口底部会提示，添加按钮仍可使用。
- Windows 请正常启动程序；管理员权限启动可能无法接收普通资源管理器的拖放。

七、界面功能
- 左侧编号按添加顺序排列，清空后重新计数。
- 文件名最多显示三行，选中后下方显示完整内容。
- 双击打开较大的多行编辑窗口，可调整大小；Ctrl + Enter 保存，Esc 取消。
- 刷新识别会覆盖手动填写的名称，建议选好命名格式后再修改。
